# Steward identity

The Steward mark represents a cloud resource within a controlled boundary: two
opposing blue brackets surround a purple resource module, with an implied S.

Use [the canonical SVG](../../web/public/brand/steward-symbol.svg) for interfaces
and [the transparent PNG](steward-symbol.png) when SVG is unavailable. The mark
uses LoomX blue `#2D7BFE` and LoomX violet `#9B51E0`. Pair it with the lowercase
wordmark **steward**, in bold sans-serif type. Use near-black `#0D0D0D` lettering
on light surfaces and light lettering on dark surfaces. Do not add a company
endorsement to the logo. Preserve the three shapes, negative space, and colors.

The browser icons in `web/public/` are raster exports of the same SVG. The
website and Steward Cloud keep copies of this symbol for independent hosting;
sync those copies when changing the canonical mark.

## Approved concept

The [approved imagegen concept](steward-logo-approved.png) is retained as the
design reference. The production SVG normalizes its geometry and flat fills for
small sizes and transparent backgrounds.

The concept was generated and refined with the built-in imagegen tool. Final
color-edit prompt:

> Use case: logo-brand. Precise color-only edit of the approved Steward logo in image 1.
> Image 1 is the EDIT TARGET: approved Steward logo with two opposing angular brackets and a central square above the wordmark "steward".
> Image 2 is a COLOR REFERENCE ONLY: the actual LoomX parent-company logo, with blue, light blue and violet.
> Preserve image 1's exact symbol geometry, silhouette, proportions, sharp corners, square center, negative spaces, layout, wordmark font, wordmark size, positioning and white background. Do not redesign, rotate, round, reshape or move any element.
> Change only the fills:
> - Both outer angular bracket shapes: a single flat LoomX blue #2D7BFE.
> - The central square: a single flat LoomX violet #9B51E0. This small violet module should stand out subtly as the resource inside the blue protective boundary.
> - The lowercase wordmark "steward": uniform near-black #0D0D0D.
> - Background: fully opaque pure white #FFFFFF.
> The final image should be the same one-logo composition as image 1, now using two restrained flat colors that harmonize with the parent brand. Crisp vector-like raster artwork with strong edges.
> Do not put the LoomX reference logo into the output. No company endorsement. The only text is exactly "steward". No "by loomx", labels, color codes or palette swatches.
> No gradients, no glow, no shadows, no lighting, no noise, no paper texture, no blur, no 3D. Keep every part inside each shape absolutely uniform in color.
