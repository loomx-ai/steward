一份可用的 AWS 资源清单，应当能说明覆盖了哪个账号、哪些地域、何时发现资源，以及哪些读取失败。本教程使用 LoomX 的 Steward 完成这些核对，不执行资源清理。

Steward 结合 AWS Cloud Control 与 Resource Explorer 发现资源。实际覆盖取决于支持的资源类型、地域可用性、权限和 Resource Explorer 视图。资源总数不能单独证明整个账号已被完整盘点。

## 开始之前

- 准备[自行部署的 Steward](../installation.md)，或使用 [Steward Cloud](https://steward.console.loomx.ai)。
- 选择商业 AWS 分区中的一个账号，以及获授权读取目标资源的身份。
- 在 AWS 中记录一个已知资源的账号 ID、地域、类型与原生标识。可以选择已有的 EC2 实例，无需创建新资源。
- 检查 [AWS 发现权限与 Resource Explorer 配置](../aws.md)。缺少索引、默认视图或权限时，请由账号管理员处理，再扩大扫描范围。

本次盘点不需要删除权限。连接验证用于确认账号身份；具体扫描结果才能说明相关资源 API 是否可读。

## 1. 核对连接背后的账号

打开用户菜单 → 设置 → 云连接 → 添加连接，选择 AWS。填入专用访问密钥对，或包含 Session Token 和过期时间的完整临时凭据，并设置能够辨认账号的连接名称。

验证后检查发现的 AWS 账号身份。回到主界面，先选择该连接，再开始扫描。

**结果核对：** 账号 ID 与已知资源所在的账号一致。Steward 不会自动导入本地 AWS profile 或 SSO 会话，也不会自动刷新 AssumeRole 凭据。临时凭据过期后，按 [AWS 指南](../aws.md)替换完整凭据。

## 2. 从一个地域开始，验证结果

打开扫描 → 开始扫描 → 指定地域，选择已知资源所在的地域。资源类型留空时，会使用范围内全部已索引类型。提交后打开任务详情。

检查各目标的完成状态与日志。某种资源读取失败时，先查看具体权限或云平台错误，再进行重试。即使任务已结束，只要仍有失败目标，清单就存在缺口。

打开资源页面，搜索原生资源标识并进入详情。对照 AWS 和刚刚运行的任务，核对地域、类型、标识、属性与最后发现时间。

**结果核对：** 在正确账号下找到同一个资源，最后发现时间来自本次扫描。找不到时，先完成下方排查，不要直接认定资源已经不存在。

## 3. 扩展到实际使用的地域

刷新连接的地域列表，确认已启用的地域。首个地域验证通过后，可以选择全部活跃地域及全局资源，也可以明确选择需要的地域并包含全局范围。

地域扫描和 VPC 扫描不会覆盖所有全局资源。例如，IAM 资源不属于 VPC 层级。Resource Explorer 在各地域的默认视图及过滤条件，也会影响发现结果。

需要盘点另一个 AWS 账号时，为它建立或选择独立连接，再重复上述核对。每个连接都有自己的清单和扫描任务；这一流程不会自动接入所有 AWS Organizations 账号，也不会将它们合并为一个清单视图。

## 4. 留下覆盖记录

在盘点审查时维护下面的记录。它是建议人工保存的核对表，不是 Steward 自动导出的报告。

| 账号 | 范围 | 观测时间 | 验证依据 | 缺口 |
| --- | --- | --- | --- | --- |
| 实际 AWS 账号 ID | 地域列表，是否包含全局资源 | 扫描任务和资源最后发现时间 | 已在 AWS 中核对的资源 ID | 失败目标、视图过滤或不支持的类型 |

每个连接分别记录。云端发生变化后，重新扫描受影响范围。资源清单是发现结果的快照，不能据此直接判断利用率、准确费用或是否可以删除资源。

## 排查缺失的 AWS 资源

| 现象 | 下一步检查 |
| --- | --- |
| 连接验证通过，但读取资源失败 | Cloud Control 权限和底层云服务的读取权限；身份验证的检查范围更小。 |
| 缺少某个地域 | AWS 中是否已启用该地域，以及是否有地域发现权限。 |
| Resource Explorer 没有返回匹配项 | 对应地域的索引、默认视图、过滤条件和 Search 权限。 |
| 缺少全局资源 | 是否选择了全局范围，以及是否支持该资源类型。 |
| 出现多个同名资源 | 对比连接、地域、类型与原生 ID。 |
| 属性仍是旧值 | 核对最后发现时间，重新扫描。 |

详细凭据和 API 要求见 [AWS 集成参考](../aws.md)。查看网络位置可继续阅读[资源关系](../topology.md)。准备删除之前，先完成[清理依赖审查](./review-cleanup-dependencies.md)。
