一份有用的 AWS 资源清单，应当说明覆盖了哪个账号和哪些地域、资源何时被发现，以及哪些读取失败了。本教程使用 LoomX 的 Steward 建立这份记录，不执行任何清理。

Steward 结合 AWS Cloud Control 与 Resource Explorer 发现资源。能发现什么取决于支持的资源类型、地域可用性、权限和 Resource Explorer 视图，因此资源总数不能单独证明整个账号已完整盘点。下面的步骤帮助你说明哪些已覆盖、哪些尚未覆盖。

## 开始之前

- [自行部署的 Steward](../installation.md)，或 [Steward Cloud](https://steward.console.loomx.ai)。
- 商业 AWS 分区中的一个账号，以及获授权读取目标资源的身份。不需要删除权限。
- 一项已知资源，例如已有的 EC2 实例。在 AWS 中记下它的账号 ID、地域、类型和原生标识，无需新建资源。
- 核对 [AWS 发现权限与 Resource Explorer 配置](../aws.md)。缺少索引、默认视图或权限时，请账号管理员先处理，再扩大访问范围。

## 1. 核对连接背后的账号

1. 打开用户菜单 → **设置** → **云连接** → **添加云连接**，选择 **AWS**。
2. 选择凭证类型，例如专用 IAM 身份的访问密钥，或包含 Session Token 和过期时间的完整会话凭证。全部类型见 [AWS 指南](../aws.md)。
3. 设置能辨认账号的连接名称，然后创建。
4. 核对 Steward 发现的 AWS 账号身份，再在**当前云连接**中选中该连接。

**检查结果**：账号 ID 与已知资源所在的账号一致。Steward 只使用你填写的凭证：不会导入本地 AWS profile 或 SSO 会话，也不会通过 AssumeRole 刷新凭证。会话凭证过期后，使用**替换凭证**。

## 2. 从一个地域开始，验证结果

1. 进入**扫描** → **开始扫描** → **选择部分地域**，勾选已知资源所在的地域。
2. **资源类型**留空，扫描该地域全部已索引类型，然后点击**创建扫描**。
3. 在扫描详情页检查各目标的状态和日志。某种资源读取失败时，查看具体的权限或云平台错误，修正后点击**重试**。
4. 进入**资源**，搜索原生标识并打开详情。对照 AWS 和刚才的扫描，核对地域、类型、标识、属性和最后发现时间。

**检查结果**：在正确账号下找到了同一项资源，最后发现时间来自本次扫描，且扫描没有失败项。扫描已结束但仍有失败项时，清单依然存在缺口。找不到资源时，先按文末表格排查，不要直接认定资源已不存在。

## 3. 扩展到实际使用的地域

1. 在**设置** → **云连接**中打开该连接的**管理地域**，点击**从云 API 刷新**。确认你使用的地域都标记为**启用**。
2. 选择**全部启用地域 + 全局**扫描；或选择**选择部分地域**，勾选需要的地域并勾选**全局**。

地域范围和 VPC 范围都不包含全局资源，例如 IAM 资源不属于 VPC 层级。Resource Explorer 在各地域的默认视图及其过滤条件，也会影响发现结果。

每个 AWS 账号需要独立的连接。为每个账号建立或选择连接，再重复上述核对。每个连接都有自己的清单和扫描任务；Steward 不会自动接入所有 AWS Organizations 账号，也不会把它们合并为一个清单视图。

**检查结果**：扫描覆盖了你使用的所有地域和全局范围，且没有失败项。

## 4. 留下覆盖记录

在盘点审查时维护下面这样的表格。它是建议人工保存的记录，不是 Steward 导出的报告。

| 账号 | 范围 | 观测时间 | 验证依据 | 缺口 |
| --- | --- | --- | --- | --- |
| 实际 AWS 账号 ID | 地域列表，是否包含全局 | 扫描任务和资源最后发现时间 | 已在 AWS 中核对的资源 ID | 失败项、被视图过滤的结果或不支持的类型 |

每个连接记录一行。云端发生变化后，重新扫描受影响的范围。资源清单是 Steward 发现结果的快照，不能据此判断利用率、准确费用，或资源是否可以安全删除。

## 排查缺失的 AWS 资源

| 现象 | 下一步检查 |
| --- | --- |
| 连接验证通过，但读取资源失败 | Cloud Control 权限和底层云服务的读取权限。验证只确认身份。 |
| 缺少某个地域 | AWS 中是否已启用该地域，以及是否有地域发现权限。 |
| Resource Explorer 没有返回匹配项 | 对应地域的索引、默认视图、过滤条件和 Search 权限。 |
| 缺少全局资源 | 是否选择了全局范围，以及是否支持该资源类型。 |
| 出现多个同名资源 | 对比连接、地域、资源类型和原生 ID。 |
| 属性仍是旧值 | 核对最后发现时间，重新扫描。 |
