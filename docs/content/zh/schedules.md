定时扫描让 Steward 按计划自动扫描云连接，资源清单不再依赖有人记得点**开始扫描**。每次运行都是一次普通扫描，结果、日志和[资源变化](./scans.md#changes)与手动扫描一样查看。

定时扫描默认不开启。在**扫描** → **定时扫描**中为当前云连接添加计划。

<span id="create"></span>

## 添加定时扫描

1. 确认左上角的**当前云连接**。定时扫描属于这个连接。
2. 进入**扫描** → **定时扫描** → **新建定时扫描**。
3. 填写**名称**，选择**扫描范围**和**资源类型**。范围选项与[开始扫描](./scans.md#scope)相同。
4. 选择**频率**和**时区**，核对**接下来 3 次运行**。
5. 点击**保存**；想先确认权限和结果，点击**保存并立即运行**。

一个云连接可以有多个定时扫描，例如每天一次全量、每 6 小时复查一次核心网络。

| 频率 | 说明 |
| --- | --- |
| **每隔几小时** | 每 1、2、3、4、6、8 或 12 小时一次，从**每天首次运行时刻**开始，每天在相同时刻运行。 |
| **每天** | 每天在指定时刻运行。 |
| **每周** | 在选中的星期几、指定时刻运行。 |
| **每月** | 每月 1–28 日中的某一天、指定时刻运行。 |
| **Cron** | 五个字段的 Cron 表达式：分 时 日 月 周。 |

时刻按所选**时区**计算，夏令时切换由时区规则处理。两次运行至少间隔 1 小时；[Steward Cloud](https://steward.console.loomx.ai) 上至少间隔 6 小时。

**全部启用地域 + 全局**按每次运行时的启用地域计算，之后新启用的地域会自动纳入。

<span id="rules"></span>

## 运行规则

**运行规则**默认折叠，标题上显示当前设置的摘要。

| 情况 | 可选处理 | 默认 |
| --- | --- | --- |
| 上一次还没结束：该云连接仍有扫描在进行 | **跳过本次**，或**等上一次结束后再运行** | 跳过本次 |
| 错过了运行时间：计划时间点 Steward 没有运行 | **服务恢复后补跑一次**，或**不补跑，等下次** | 补跑一次 |
| 有扫描项失败 | **结束后自动重试一次**，或**不重试** | 自动重试一次 |
| 整次扫描失败 | 连续 2、3 或 5 次后暂停计划 | 3 次 |

- 错过多个时间点时，最多补跑一次。
- 暂停中的手动扫描不算"仍在进行"，不会挡住定时扫描。
- 整次扫描失败是指所有扫描项都失败，或扫描未能启动，常见原因是凭证失效或授权被撤销。部分扫描项失败不计入。

<span id="runs"></span>

## 查看运行记录

点击定时扫描的名称打开详情。**运行记录**为每个计划时间点列一行，包括没有真正运行的时间点：

| 结果 | 含义 |
| --- | --- |
| **成功**、**失败** | 扫描的最终状态。 |
| **N 项失败** | 部分扫描项失败；下方显示第一项的地域、资源类型和原因，以及是否已自动重试。 |
| **已跳过** | 该云连接仍有扫描在进行，或 Steward 当时没有运行且规则为不补跑。 |
| **未能启动** | 扫描没有创建成功，例如云连接未通过验证。 |

计划时间下方标注**补跑**的，是 Steward 恢复运行后补跑的时间点；标注**立即运行**的，是有人点击了**立即运行**，它不改变下次运行时间。

**资源变化**一列显示 `+新增 −消失 ~修改`，点击查看明细。**扫描**页的**扫描任务**列表中，定时扫描发起的任务在**发起人**一栏显示计划名称；用**来源**筛选手动或定时扫描。

<span id="pause"></span>

## 自动暂停与恢复

连续失败达到阈值后，Steward 暂停该定时扫描，避免反复调用云 API。暂停后：

- 定时扫描列表、计划详情和其他页面顶部显示暂停原因和最近一次失败的原因。
- 左上角的云连接切换器中，该连接显示红色的**已暂停**。
- 在**设置** → **云连接**中替换凭证并通过验证后，因连续失败而暂停的计划会自动恢复，从下一个计划时间开始运行，暂停期间的时间点不补跑。

也可以手动**暂停**或**恢复**定时扫描。手动暂停的计划不会被自动恢复。

<span id="freshness"></span>

## 数据新鲜度

**资源全景**、**资源**、**清理**和**治理发现**页面右上角显示当前连接**完整扫描**的时间和下次运行时间。完整扫描指范围为**全部启用地域 + 全局**、不限资源类型、且全部成功的扫描；手动扫描也算。按地域、按网络或限定资源类型的扫描不会刷新这个时间。

云连接切换器中每个连接旁边的圆点：

| 圆点 | 含义 |
| --- | --- |
| 绿色 | 已开启定时扫描，24 小时内有完整扫描 |
| 黄色 | 已开启定时扫描，但完整扫描超过 24 小时 |
| 红色 | 有定时扫描被自动暂停 |
| 灰色 | 没有开启的定时扫描 |

删除密钥或身份要求完整扫描。清理任务因此被阻断时，任务页会显示最近一次完整扫描的时间，并可直接**开始完整扫描**。参阅[清理资源](./cleanup.md#review)。

<span id="settings"></span>

## 全局设置

管理员在**设置** → **定时扫描**中管理：

- **新连接的默认计划**：开启后，云连接首次通过验证时自动创建「每日全量」，范围为全部启用地域 + 全局，每天凌晨 1:00–6:00 之间随机一个时刻运行，避免多个连接同时扫描。默认关闭；已有的云连接不受影响。
- **默认时区**：新建定时扫描默认使用的时区。
- **定时扫描记录保留**：7、30、90 天或永久，默认 30 天。只清理定时扫描发起的扫描任务、日志和资源变化；手动扫描不受影响，每个计划最近一次成功的扫描始终保留。
- **全部定时扫描**：所有云连接的计划、状态、下次运行和完整扫描时间。点击某个连接即切换过去并打开它的定时扫描。

<span id="notifications"></span>

## 失败通知

管理员在**设置** → **通知**中添加通知渠道，在定时扫描失败、部分失败或被自动暂停时收到消息。

| 类型 | 需要填写 |
| --- | --- |
| **飞书**、**钉钉** | 机器人的 Webhook 地址；开启了签名校验时再填**加签密钥**。开启了关键词校验时，把 `Steward` 设为关键词。 |
| **企业微信**、**Slack** | 机器人或 Incoming Webhook 的地址。 |
| **Webhook** | 任意接收 JSON 的地址。请求体包含 `event`、`schedule`、`connection`、`scan_task_id`、`detail` 和一段可读的 `text`。 |

- 每个渠道可以选择通知事件和消息语言。点击**发送测试**确认能送达；最近一次发送的结果显示在渠道下方。
- Webhook 地址和加签密钥使用与云凭证相同的密钥加密保存，界面只显示末尾几位。
- 发送失败会重试两次，不影响扫描本身。
- 设置 `STEWARD_PUBLIC_URL` 后，消息中会附带扫描详情链接。参阅[配置参考](./configuration.md)。
- Steward Cloud 的通知渠道只能发送到公网地址。

<aside class="docs-note">定时扫描在 Steward 服务运行时执行。在笔记本上本机运行时，合盖或退出期间不会扫描，恢复后按<strong>错过了运行时间</strong>的规则处理。需要稳定的定时扫描，请<a href="./deployment.md">在服务器上部署</a>。</aside>
