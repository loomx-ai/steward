一个云连接让 Steward 访问一个云身份：一个阿里云账号、AWS 账号、Google Cloud 项目或 Azure 订阅。每个连接拥有独立的资源清单、扫描和清理任务。需要盘点几个账号，就添加几个连接。

<span id="credentials"></span>

## 选择凭证类型

为 Steward 使用专用的云身份。先授予盘点所需的读取权限；需要清理时，再只为计划清理的资源类型补充删除权限。

| 云厂商 | 密钥类凭证 | 浏览器登录 |
| --- | --- | --- |
| [阿里云](./alicloud.md) | AccessKey ID + AccessKey Secret。使用 STS 时，另填 Security Token 和到期时间。 | 支持 |
| [AWS](./aws.md) | Access Key ID + Secret Access Key。使用临时凭证时，另填 Session Token 和到期时间。 | 通过 IAM Identity Center |
| [Google Cloud（GCP）](./gcp.md) | 项目 ID + 服务账号 JSON 密钥 | 支持 |
| [Microsoft Azure](./azure.md) | 订阅 ID + 租户 ID + 应用（客户端）ID + 客户端密钥 | 支持 |

如何选择：

- **密钥类凭证**：适合长期稳定、无人值守的使用场景和服务器部署，也是 Steward Cloud 中可用的方式。
- **浏览器登录**：在自己电脑上试用 Steward 最快的方式。连接能读取的范围与你个人账号一致。
- **[OIDC 工作负载身份](./oidc.md)**：无需保存长期云密钥。服务运维者完成配置后，四个云均可使用。

Steward 会加密保存凭证。验证通过只说明身份有效，不代表每种资源都有读取权限——扫描会逐项报告缺少的权限。盘点和清理所需的权限见上表链接的各云指南。

<span id="browser"></span>

### 用浏览器登录

不粘贴密钥，也可以在云厂商自己的登录页完成授权。Steward 在回环地址上接收授权结果，只保存换回的令牌。

各云需要填写的内容：

- **阿里云**：选择与账号一致的中国站或国际站，无需填写其他内容。
- **Google Cloud**：登录后，从账号可访问的项目中选择一个。
- **Microsoft Azure**：登录后，从账号可访问的订阅中选择一个，租户随之确定。
- **AWS**：登录前先填写 IAM Identity Center 的起始 URL 和所在区域，它们决定登录哪个目录；登录后，从分配给你的账号和角色中选择一组。AWS 没有账号级的浏览器登录，这种方式依赖 IAM Identity Center；未启用时请改用 Access Key 或 OIDC。

选择这种方式前，需要了解两处限制：

- **浏览器和 Steward 服务必须运行在同一台机器上。** 云厂商会把授权重定向到 `127.0.0.1`，也就是运行浏览器的机器，部署在其他主机上的 Steward 服务收不到。远程部署请使用 Access Key 或 [OIDC](./oidc.md)。Steward Cloud 出于同样的原因不提供浏览器登录。
- **连接以你本人的身份访问，而不是服务身份。** 它能读取的内容与你的账号完全一致：你看不到的资源类型不会出现在清单中，缺少的目录或数据面权限会表现为失败的扫描项。需要长期稳定、无人值守的权限范围时，请使用服务账号、服务主体或 Access Key。

浏览器登录在有效期内会自动续期。如果授权被撤销，或 AWS 客户端注册到了 90 天期限，连接会提示需要重新授权，使用**替换凭证**重新登录即可。

<span id="add"></span>

## 添加连接

1. 打开用户菜单 → **设置** → **云连接** → **添加云连接**。
2. 填写易于识别的名称，例如「生产账号」，选择云厂商和凭证类型。
3. 填写凭证或完成登录，然后创建连接。Steward 会先验证云身份，再保存。
4. 查看地域列表。地域发现尚未完成时，稍后刷新；缺少在用的地域时，按云指南检查地域查询权限，或手动添加该地域。

接下来，选中这个连接并[开始扫描](./scans.md)。

<span id="maintain"></span>

## 维护连接

- **轮换或续期凭证**：使用**替换凭证**。新凭证必须属于同一个云身份；要换成其他账号，请新建连接。
- **验证失败时**：展开错误详情查看错误码和请求 ID，再检查权限、到期时间，以及密钥 ID 与密钥是否配对。
- **删除连接**：会永久销毁已保存的凭证，历史记录仍会保留，云上资源不受任何影响。确认时需要输入连接名称。
