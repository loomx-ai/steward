在**资源**页面查找某项资源，核对 Steward 记录的信息，并把它加入资源清单等待清理审核。

<span id="find"></span>

## 查找资源

1. 确认左上角的**当前云连接**。**资源**只列出这个连接下的资源。
2. 进入**资源**，在搜索框中输入名称、云资源 ID 或类型，例如 `api-01` 或 `i-demo-api01`。

多个账号或地域使用相同名称时，用云资源 ID 搜索。

<span id="query"></span>

## 组合查询条件

1. 点击搜索框左侧的模式按钮，切换到高级查询。
2. 输入查询条件，输入时会提示可用的字段和取值。
3. 按 Enter 应用。

```
name contains "api" and region = "ap-southeast-1"
```

高级查询支持 `and`、`or`、`not` 和括号。官网公开演示只支持普通搜索；高级查询需要本地服务或 Steward Cloud。

<span id="details"></span>

## 查看详情

点击资源名称打开详情：

- **概览**显示属性和标签。
- **关系**显示相关资源。
- **在资源全景中查看**显示资源在网络中的位置。

**最后发现时间**是扫描最后一次读取该资源的时间，不是实时状态。如果它早于最近的变更，请[重新扫描](./scans.md#freshness)。删除之前，先核对资源所属账号、地域和云资源 ID。

<span id="selection"></span>

## 加入资源清单

1. 勾选要清理的行。表头的复选框会选中本页所有可选资源。
2. 点击**加入资源清单 (N)**。这些行会标记为**待清理**。如果所选行都已在清单中，按钮会变为**从资源清单移除 (N)**。
3. 点击右下角的**资源清单**核对目标，再点击**创建清理任务**。

资源清单只用来收集目标。创建任务、完成审核并点击**开始清理**之前，不会删除任何资源。参阅[清理资源](./cleanup.md)。

### 标记为脏资源

确认某条记录无效后，可以在该行或详情页点击**标记为脏资源**。清理会忽略脏资源。该标记不会删除云端资源，也不应用来绕过依赖阻断项。点击**取消脏资源标记**可撤销。
